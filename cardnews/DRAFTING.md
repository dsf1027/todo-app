# 카드뉴스 초안 작성 규칙 (Claude용)

매일 초안을 쓸 때 이 문서를 따른다. 결과물은 `cardnews/drafts/<YYYY-MM-DD>.json` 하나와 사진(`cardnews/drafts/images/`).
게시는 사람이 확인·승인한 뒤에만 한다.

## 1. 주제 고르기
- 범위: 경제·지정학 리스크 중 **오늘(한국 시간) 기준 24시간 안에 보도됐거나, 오늘·내일 일어나는** 이슈 하나.
- 1주일 넘게 이어진 이슈라도 오늘 새로 나온 숫자·사건이 없으면 고르지 않는다 ("옛날 주제"가 됨).
- 검색 결과의 날짜를 믿지 말고 원문 기사의 입력 일시를 확인한다 (같은 제목의 다른 해·다른 달 기사가 섞여 나옴).
- 독자: 경제 뉴스가 어려운 20~30대. "그래서 내 지갑에 뭐가 달라지나"로 이어질 수 있는 주제를 고른다.
- 같은 주제를 7일 안에 다시 다루지 않는다 (`drafts/`의 최근 파일을 확인).

## 2. 사실 확인 (가장 중요)
- 카드에 들어가는 **숫자·날짜·인용은 전부 원문 기사나 1차 자료를 직접 열어 확인**한 것만 쓴다. 검색 요약만 보고 쓰지 않는다.
- 숫자에는 **기준 시점**을 붙인다. 예: "10월 20일 장중", "2024년 평균".
- 출처는 1차 자료(기관·공식 통계: 한국은행, 통계청, EIA, IMF 등)를 우선하고, 없으면 언론 보도를 쓴다.
- 확인이 안 되는 내용은 빼거나 "~경향", "~수 있어요"로 쓴다. 단정하지 않는다.
- 전망·투자 조언은 쓰지 않는다 ("사세요", "오릅니다" 금지).

## 3. 카드 구성 (형식: `format: "card"`, 1080×1350, 인스타그램 캐러셀)
- **최대 5장** (사용자 지정). 기본 구성:
  1. 표지: `kicker`(날짜·분류) + 질문형 `title`
  2~4. 한 장에 핵심 하나: `kicker`(① 시장 / ② 계기 처럼 짧게), `title` 2줄 이내, `sub` 2줄 이내 (한 줄 약 22자)
  - 주제에 맞으면 4장을 "내 지갑엔?" 카드로 쓴다.
  5. `outro`: `sources` 전부(매체·날짜·제목), `disclaimer`
- 계정 표기: `brand`(계정 이름)는 넣지 않고, `handle`은 `@issuehororok` (사용자 지정). 캡션에도 계정 이름 해시태그를 넣지 않는다.
- `**강조**`는 카드당 1곳.
- 카드에는 분야 표시(경제 등)를 넣지 않는다 (다양한 주제를 다룸). `category`는 강조색만 정함: `economy`(초록) / `policy`(파랑) / `tech`(보라). `mood`: `serious` / `calm` / `positive` (릴스용, 캐러셀에서는 안 씀).

## 4. 사진
- **사진은 카드 내용을 직접 보여줘야 한다 (사용자 지정).** 주식이면 차트·시세 화면, 반도체면 칩·회로, AI 기업이면 서버·데이터센터처럼 보자마자 주제를 알 수 있는 사진.
  비유 사진(불꽃=급등, 모래시계=멈춤, 추상 도형=AI)은 쓰지 않는다. 고르는 순서: ① 관련 있는 사진만 후보로 → ② 그중 글자 자리가 빈 것.
- 후보는 가로 사진까지 넉넉히 받는다 (`per_page` 30 이상). 가로 사진은 카드에서 좌우가 잘리므로 렌더링 후 주제가 남아 있는지 확인한다.
- `imageQuery`(영문)로 `fetch-images.js`를 쓰거나, 후보를 보고 고른 Pixabay ID로 받는다.
- 받은 사진은 **반드시 눈으로 확인**한다. 빼야 하는 것: 알아볼 수 있는 사람 얼굴(지폐 초상 포함), 브랜드 로고·상표·간판, 국기, 주제와 무관하거나 오해를 부르는 사진(예: Fed 기사에 의회 건물), 술·담배, 일러스트·클립아트, 흰 배경.
- Pixabay 사진 페이지 주소(`imageSource`)의 태그도 확인한다 (예: "man-drinking-whiskey"는 카드에서 잘린 부분에 술이 있었음).
- 글자는 **매 장 같은 위치(위쪽)** 에 온다. 그래서 사진은 **위쪽(글자 자리)에 사물이 없는** 것만 고른다 (사용자 지정).
  - `node cardnews/photo-space.js <사진...>`으로 점수를 매긴다: 20 미만 좋음 / 20~60 눈으로 확인 / 60 이상 탈락.
  - 사물이 조금 걸치면 `imagePosition`으로 옮긴다: 세로 사진은 `center top`(사물이 아래로), 가로 사진은 `left center`(사물이 오른쪽으로)·`right center`. 세로 사진은 `--position=top`으로 다시 점수를 잰다.
  - 렌더링 후 글자와 사물이 겹치는지 눈으로 최종 확인한다 (점수는 매끈한 사물을 놓칠 수 있음).
- `credit`, `imageSource`를 채운다.

## 5. 캡션 (`caption`)
- 2,200자·해시태그 30개 이내 (인스타그램 제한). 실제로는 5~10개.
- 구성: 한 줄 요약 → 핵심 3줄 → 출처(매체·날짜) → "정보 제공 목적이며 투자 권유가 아닙니다." → 해시태그.

## 6. 확인 후 제출
- `node cardnews/render.js <json> <폴더> --jpg`로 렌더링하고 모든 장을 눈으로 확인 (글자 잘림·가독성·사진 적합성).
- 사람에게 넘길 때: 카드 이미지 + 주제 선정 이유 + 확인한 출처 목록 + 확신이 낮은 부분.
